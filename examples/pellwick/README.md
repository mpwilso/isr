Pellwick is an invented company. The `*.story.md` files are byte-for-byte copies of Loupe's `examples/pellwick/expected/` stories at commit 91656eafd2aae4c79b856ee7cd31adcc6a2b3359 (https://github.com/mpwilso/loupe).
The `*.record/` folders are invented build records in Parallax's task folder format, and each `*.script.md` is the acceptance script ISR should write for them, written by hand.
